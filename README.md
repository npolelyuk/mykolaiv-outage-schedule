# Світло Миколаїв (LightMykolaiv)

**Світло Миколаїв** — це сучасний, швидкий та зручний Android-додаток для моніторингу графіків погодинних відключень електроенергії (ГПВ) від АТ «Миколаївобленерго».

Додаток створений для того, щоб ви завжди знали актуальний стан електропостачання вашої черги, отримували своєчасні сповіщення перед відключенням або ввімкненням світла та мали зручний віджет на робочому столі.

---

## ✨ Основні можливості

* **📊 Актуальний графік відключень:**
  * Відображення розкладу на сьогодні та на завтра (якщо опубліковано обленерго).
  * Інтуїтивна 24-годинна шкала з кольоровими інтервалами (Є світло / Немає / Можливо).
  * Детальний погодинний та півгодинний розклад для кожної підчерги.

* **⏱️ Таймер зворотного відліку:**
  * Велика інформативна картка показує поточний статус і точний час до наступної зміни (до ввімкнення або вимкнення).
  * Індикатор точного часу останнього оновлення даних із сайту.

* **🔔 Розумні сповіщення (Push):**
  * Попередження за вказану кількість хвилин до відключення світла (налаштовується від 5 до 60 хв).
  * Попередження за вказану кількість хвилин до ввімкнення світла (налаштовується від 1 до 30 хв).
  * Можливість увімкнути/вимкнути сповіщення для зони «Можливо» (жовта зона).
  * Сповіщення про появу графіка на наступний день, щойно його оприлюднить «Миколаївобленерго».
  * Автономна робота у фоні завдяки Android WorkManager.

* **📱 Інтерактивний віджет для робочого столу:**
  * Створений на сучасній бібліотеці **Jetpack Glance**.
  * Відображає поточний статус, чергу, час до зміни стану та повну добову шкалу в єдиній кольоровій гамі з додатком.
  * Кнопка ручного оновлення прямо з віджета.
  * Швидке додавання на головний екран в один дотик.

* **🔄 Оновлення жестом (Pull-to-Refresh):**
  * Можливість миттєво оновити інформацію просто потягнувши екран зверху вниз.

* **🌐 Меню корисних посилань:**
  * Швидкий перехід до офіційного графіка: `off.energy.mk.ua`.
  * Перехід до офіційного Telegram-каналу «Миколаївобленерго»: `t.me/mk_energy_ua`.
  * Перегляд аварійних та планових відключень на сайті: `energy.mk.ua/vidklyuchennya`.

* **🎨 Персоналізація та теми:**
  * Підтримка світлої, темної та автоматичної (системної) теми оформлення.
  * Оптимізована висококонтрастна темна палітра для економії заряду AMOLED-екранів.

* **🚀 Автоматична перевірка оновлень:**
  * Вбудована перевірка свіжих релізів через GitHub API.
  * Сповіщення при появі нової версії з можливістю завантажити та оновити додаток в один дотик.
  * Ручна перевірка у меню налаштувань.

## 🛠 Технічний стек

* **Мова:** Kotlin
* **UI Framework:** Jetpack Compose, Material 3
* **Архітектура:** MVVM (Model-View-ViewModel), Kotlin Coroutines & Flow (StateFlow)
* **Віджети:** AndroidX Glance (GlanceAppWidget)
* **Фонові задачі:** AndroidX WorkManager (періодичний фоновий моніторинг)
* **Парсинг та мережа:** Jsoup (парсинг офіційного сайту), Retrofit & Gson (GitHub Releases API)
* **CI/CD:** GitHub Actions (автоматична збірка та публікація підписаного Release APK при створенні git-тегу)

## 📥 Встановлення

Ви завжди можете завантажити найновіший готовий файл `.apk` на сторінці релизів:

👉 **[Завантажити останній реліз (Releases)](https://github.com/npolelyuk/mykolaiv-outage-schedule/releases/latest)**

1. Завантажте файл `LightMykolaiv-vX.X.X.apk` на ваш Android-пристрій.
2. Дозвольте встановлення з невідомих джерел (якщо з'явиться запит системи).
3. Відкрийте файл та завершіть встановлення.
4. Оберіть вашу чергу та підчергу в додатку й додайте віджет на головний екран.

## ⚙️ Збірка проекту з вихідного коду

### Вимоги:
* Android Studio Ladybug (або новіша)
* JDK 17
* Android SDK (API 36, мінімальна версія Android 8.0 Oreo / API 26)

### Кроки для збірки:
```bash
# Клонування репозиторію
git clone https://github.com/npolelyuk/mykolaiv-outage-schedule.git
cd mykolaiv-outage-schedule

# Збірка Debug APK
./gradlew assembleDebug

# Збірка Release APK
./gradlew assembleRelease
```
